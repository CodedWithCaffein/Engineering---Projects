## Use the calculator

Open [Gear_Calculator.html](Gear_Calculator.html), click GitHub's **Download raw file** button, then open the downloaded file in a browser. No installation or internet connection is needed after downloading. GitHub displays the source code; it does not run the calculator on this page.

You can also open that same file in Notepad or VS Code. All the HTML, CSS, and JavaScript is in one file.

## Background

In late September 2026, my Principles of Engineering class at CTC got me interested in how gear sizes affect torque and speed. I wanted a small project where I could enter different combinations and check the results.

## Progress

The calculator handles two to nine gears using tooth counts or pitch diameters. Connections can be external meshes, shared shafts, or uncrossed chains. The interface is deliberately basic, with uneven spacing and ordinary browser buttons. Results assume no friction losses.
